# Obstacle Detecting Line Tracer

## 📌 프로젝트 개요
본 프로젝트는 IR 센서를 이용한 라인트레이싱과 초음파 센서를 이용한 장애물 감지를 결합한 2륜 주행 시스템입니다.  
주행 중 전방 장애물을 감지하면 기존 라인트레이싱 동작을 중단하고 정지하도록 설계하여, 기본적인 안전 제어 동작을 구현하는 것을 목표로 했습니다.

---

## 🛠 사용 하드웨어
- IR 센서 2개 (좌/우 라인 감지)
- 초음파 센서 (HC-SR04)
- DC 모터 2개
- 모터 드라이버 (TB6612FNG)
- 부저 (Buzzer)
- LED (경고 표시)

---

## ⚙️ 시스템 동작 구조

1. 초음파 센서를 이용하여 전방 거리 측정  
2. 거리 값에 따라 장애물 감지 여부 판단  
3. 장애물이 감지되면 경고 및 정지 수행  
4. 장애물이 없을 경우 라인트레이싱 수행  

---

## 🚗 라인트레이싱

- IR 센서 값을 `analogRead()`로 읽어 임계값(Threshold)을 기준으로 판단  
- 조건문 기반으로 주행 방향 결정  

| 상태 | 동작 |
|------|------|
| 좌/우 센서 모두 감지 | 직진 |
| 왼쪽만 감지 | 좌회전 |
| 오른쪽만 감지 | 우회전 |
| 모두 미감지 | 정지 |

**임계값 기반 조건 분기 방식**

---

## 🚧 장애물 감지 및 경고

- 초음파 센서를 이용하여 거리(cm) 측정  
- 거리 기준에 따라 다음과 같이 동작  

| 거리 | 동작 |
|------|------|
| ≤ 12cm | LED ON + 부저 경고 |
| ≤ 5cm  | 모터 정지 |

- `map()` 함수를 사용하여 거리와 부저 울림 간격을 연동  
  → 장애물과 가까워질수록 경고 주기가 빨라짐  

👉 장애물 감지 시 라인트레이싱 동작 중단

---

## ⚡ 모터 제어

- PWM(`analogWrite`)을 이용하여 속도 제어  
- GPIO를 이용하여 방향 제어  

👉 속도와 방향을 분리하여 제어

---

## 🧠 주요 특징

- 라인트레이싱 + 장애물 감지 기능 결합
- 장애물 감지 우선순위 기반 제어 구조
- 거리 기반 경고 시스템 구현 (부저 주기 변화)
- PWM을 이용한 모터 속도 제어

---

## ⚠️ 제한 사항

- 장애물 회피 기능 없음 (정지만 수행)
- PID 제어 미적용 (단순 조건문 기반 제어)
- 센서 노이즈에 대한 고급 필터링 미적용
👉 신입 학사 수준에서 개인이 스스로 한 프로젝트
